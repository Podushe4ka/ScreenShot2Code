# Конвертер WebUI → self-contained HTML

Превращает `ronantakizawa/webui` в drafting-пары формата
[`SFT/DATA_FORMAT_CONTRACT.md`](../../../SFT/DATA_FORMAT_CONTRACT.md).

## Зачем понадобился третий конвертер

| Источник | Где лежит CSS | Чем лечится |
|---|---|---|
| WebSight | utility-классы Tailwind | `precompile_tailwind` |
| WebCode2M | внутри страницы (`<style>`, `style=`) | санитайз внешних ресурсов |
| **WebUI** | **отдельной колонкой `css` — весь стайлшит сайта** | **tree-shaking** |

У дизайн-систем колонка `css` — это 170–470 КБ на страницу в сотню DOM-узлов. Отсюда
p99 = 171 851 токен ([`Data/eda/datasets_overview.md`](../../eda/datasets_overview.md)),
из-за которого WebUI и не взяли в MVP. Обрезка по длине здесь не работает: обрезанный
стайлшит ломает страницу. Работает только выбрасывание правил, которые к этой странице
не применились.

## Конвейер

```
fetch_columns.py      фаза 0: только текстовые колонки parquet (без image/bboxes),
                      дедуп по sample_id -> одна строка на страницу (desktop)
        │
convert_parallel.py   фаза 1-3: пул воркеров -> convert_lib.convert_one -> staging
        │
        ├─ cssprune.strip_external_urls   url(...) наружу -> none
        ├─ assemble_page                  html + css, снос script/link/iframe, де-блоб data-URI
        ├─ cssprune.prefilter             soupsieve по DOM, без браузера
        ├─ used_css_ranges                CDP CSS.startRuleUsageTracking при 1280
        ├─ cssprune.rebuild_from_usage    минимальный стайлшит (+ @font-face/@keyframes/@media)
        ├─ cssprune.prune_custom_props    неиспользуемые --переменные
        ├─ replace_images_with_placeholder   канонический серый блок
        ├─ accept_page                    рендер ДО/ПОСЛЕ + метрика Design2Code
        └─ render_png                     свой скриншот (Evaluation/metrics_only/render.py)
```

Запуск:

```bash
python fetch_columns.py --out webui_desktop.jsonl.gz
```

```bash
python convert_parallel.py --cache webui_desktop.jsonl.gz --out /path/stage_webui --n-workers 4
```

## Почему скриншот свой, а не из датасета

В WebUI картинка снята при 1280×720 — это **только первый экран**, а колонка `html`
содержит страницу целиком. Пара «скриншот шапки → код всей страницы» рассогласована, и
модель училась бы дописывать то, чего на входе не видно. Поэтому шаг 5 — ре-рендер тем же
движком, которым меряется бенч (`Evaluation/metrics_only/render.py`, ширина 1280, полная
высота).

## Приёмка (шаг 6) — два сигнала

Страница рендерится **до** и **после** tree-shaking, и результаты сравниваются:

1. **метрика Design2Code** (`metrics.score_pair`) — та же, которой меряют модель;
2. **попиксельное совпадение** тех же двух рендеров.

Второй сигнал не подстраховка ради удобства. На почти пустой странице (одна кнопка на
белом фоне) метрика не находит ни одного блока и возвращает **ровно 0** — это артефакт
измерения, а не сломанная конвертация: на смоуке так терялось 8 страниц из 40, все —
витрины отдельных компонентов. Пиксели такую страницу измеряют корректно и при этом ловят
реальную поломку шейкера строже метрики (поехала вёрстка — поехала картинка).

Метрика считается там, где она решает (пиксели разошлись) и на каждой `--metric-every`-й
странице для отчёта. Полная метрика на каждой странице — это CLIP плюс четыре рендера, и
она съедала ~80% времени конвейера (0.46 стр/с против 2.3 стр/с на четырёх воркерах).

## Отбраковка `unstyled`

У части источников колонка `css` **не содержит стайлшита компонентов**. На
`sap-fundamental-styles` в 172 КБ лежат только служебные стили Storybook (`.sb-*`) и 58
блоков `:root` с токенами темы, а классов разметки (`fd-navigation`) в CSS нет вообще —
страница физически не восстанавливается из того, что дал источник.

Шаг 6 это не ловит и не может: до и после шейкинга такая страница одинаково
неоформленная, метрика честно даёт ~1.0. Ловит `styling_coverage` — доля классов
разметки, у которых в CSS есть хоть одно правило. Порог «мало объявлений» тут не годится:
он одинаково рубит и потерянный стайлшит, и честную простую вёрстку без CSS.

## Файлы

| Файл | Что делает |
|---|---|
| `fetch_columns.py` | фаза 0: текстовые колонки из parquet, дедуп по `sample_id` |
| `cssprune.py` | разбор CSS в дерево с оффсетами, префильтр, пересборка по CDP |
| `convert_lib.py` | шаги 2–6 для одной страницы |
| `convert_parallel.py` | пул воркеров, staging, токены, near-dup, отчёт приёмки |
