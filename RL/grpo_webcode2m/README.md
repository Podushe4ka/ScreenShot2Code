# GRPO-пайплайн для WebCode2M

Экспериментальный RL-пайплайн для Screenshot-to-Code на базе verl и Qwen3.5-4B.

## Пайплайн

1. Подготовка WebCode2M в формате verl.
2. Генерация полного HTML/CSS моделью.
3. Рендер HTML через Playwright.
4. Сравнение результата с целевым скриншотом.
5. Использование визуальной метрики как reward для GRPO.

Невалидный или неотрендерившийся HTML получает reward 0.

## Основные файлы

- `prepare_verl_dataset.py` — создание smoke-датасета.
- `prepare_webcode2m_verl.py` — преобразование WebCode2M в формат verl.
- `renderer.py` — рендер HTML через Playwright.
- `reward.py` — попиксельное сравнение изображений.
- `screenshot_reward.py` — извлечение HTML, рендер и расчёт reward.
- `build_diversity5_gallery.py` — галерея для ручного сравнения генераций.
- `launchers/` — диагностические запуски GRPO и валидации.

## Текущий статус

Полный пайплайн от генерации HTML до GRPO проверен на WebCode2M.
Лимит 6144 токена уменьшил число обрезанных HTML, а ненулевая temperature дала разнообразные генерации.
Текущий pixel similarity reward остаётся диагностическим: он может завышать оценку из-за больших совпадающих областей фона.
